# AI Chat 重设计：定稿与还原计划（2026-11-14）

- **设计稿**：Pencil 顶层画板 `Kaf7E`「ZW · AI Chat 重设计 2026-11-14」。
- **证据**：设计导出和"当前 vs 新"对照图在 `ZeroWork-evidence/ai-chat-design/`（design/、compare/、current/）。

## 用户拍板
1. 整体方向认可，可以开始还原。
2. 用户气泡用中性的 `bg_active`，不再用饱和的 accent 实底。
3. 停靠宽度 ≥ 760 时，对话和输入区共用一个 720 宽的居中内容列。
4. **新增**"新消息"提示：用户上翻查看历史时，如果来了新回复，就在底部显示"↓ 新消息"，点击后回到底部。代码里原来没有这个功能，这次新增。
5. 错误恢复卡改用原生 Alert（danger 浅底），去掉原来的 warn 色加灰卡。
6. **保留**"～回合结束～"的装饰：用户没有选择删除。还原时沿用现在的元素，只按新尺度调整间距和字号，并且要解决 320 宽下折成两行的问题。

## 主会话判定
- **未配置模型**：空状态里放引导；已有对话历史时，在输入区上方放原生 Alert。两种情况不同时出现。
- **死代码直接删除**：生产路径上恒为 null 的旧审批视图（`ai_tool_approval_view` / `ai_host_approval_view`），以及欢迎页里永远隐藏的状态行。
- **停靠头部标题**统一用 12/600 fg_primary，和浮动外框一致。
- **审批面板里的 Esc**：以代码现有行为为准，先核实，不改变语义。
- **截图中发现的问题**，在还原包里一并核实并修复：
  - 执行中时节点树里有 `ai.stop`，但界面上看不到；
  - 停靠在分屏里时，launcher 压在输入区右下角。

## 还原拆包
- **U0**：zenit 上游补齐 7 项能力，每项一个提交。
  1. Markdown：代码块可去边框，提供头部槽，支持最大高度和双向滚动；表格加"仅横线"变体。
  2. Textarea：加附件条和工具行插槽，以及容器级的聚焦样式。
  3. Menu：选项支持说明文字，右侧可放 Tag。
  4. Disclosure：一行触发，展开后用左侧轨道。
  5. Alert：加 actions 和可折叠详情。
  6. Chip：附件规格。
  7. Card：bubble 变体，或无边框参数。
- **P1**：输入区。
- **P2**：消息流排版。
- **P3**：步骤组与工具卡。
- **P4**：审批面板与排队。
- **P5**：恢复卡、反馈、回合状态。
- **P6**：弹层，以及子对话框头部。
- **P7**：空状态、宽度规则、新消息提示。

## P6 / P7 落地（ai-redesign-c）
- **会话列表 / 子智能体弹层（O7 / O8）**：原生 `W.Popover` 默认面板（去掉旧的底色 / 圆角 / 阴影覆盖），宽 `min(360, 面板宽 − 16)`、横向夹在面板左右各 8 以内（`sessions/view/ai_popover_anchor.zig`），会话列表高度随行数、不超出面板；头部按 PanelHeader（图标 14 · 标题 12/600 · 计数 11 · 原生 ghost sm 关闭）；会话行标签改原生 `W.Tag` sm、操作改原生 ghost xs 图标按钮；子智能体行改原生 `W.Pressable`（44 高，logo 24）。两个弹层挂在内容节点上，浮动 / 停靠都在。
- **子对话框头部（O9）**：与统一外框同规格（bot 14 accent · 标题 12/600 · 状态原生 `W.Tag` · 父对话副标题 11 · 原生 ghost sm 按钮 24），头部 36、内边距 0 8 0 16。
- **图片预览（O10）**：头部 36（标题 13/600 · 原生关闭）· 图片区 bg-secondary · 底栏（来源说明 11 · 原生 secondary sm“移除图片” · primary sm“保留图片”）。**关闭确认（O11）**：沿用 confirm-undo 的 `confirm`（宽 320）。**停靠“更多”（O5）**：菜单项带图标。
- **空状态**：未配置 = 原生 `W.Empty`（动作是 Empty 原生的 secondary sm，设计稿写 primary，以原生为准）；已有对话历史时才在输入区上方放原生 Alert（`ai_unconfigured_view.placement`，两者不同时出现）；欢迎页按 A2 改为左对齐（sparkles 20 · 16/600 标题 · 快捷提问 · 最近会话复用 ai_session_row）；删除恒隐藏的状态行与不可达的“配置本地模型”按钮。
- **宽度规则**：停靠宽 ≥ 760 时 `ai.content` 左右留白，对话视口与输入区共用 720 居中列（`pane/model/ai_content_column.zig`）；浮动 320 / 420 时标题被挤压前副标题先隐藏，最窄时空白占位让出间距（`float_chrome.zig`），“AI 助手”不再被截成“AI…”。
- **停靠头部**：AI 窗格标题 12/600 fg-primary；launcher 停放位置压在停靠的 AI 窗格上时改停到窗格之外（`ai_launcher.avoidPane`）。
- **新消息提示**：`ai_tail_follow` 记录读者离开底部后的新输出，视口底部居中、离下缘 8 显示原生 secondary sm Button“新消息”，点击 240 ms ease-out 回到底部并恢复跟随（减少动态效果时直接到底），读者自己滚到底时消失。
