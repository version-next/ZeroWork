# ZeroWork 术语表

- 依据：`docs/ui-revamp/CONSISTENCY_AUDIT.md` 文末“用户拍板（2026-11-14）”第 3 条，以及 #7、#8、#14。
- 范围：用户能看到的文字（界面、菜单、提示、通知、确认框、无障碍标签）。标识符、test_id、配置键、日志与发给模型的工具说明不受约束。
- 护栏：`zig build check-arch` 的 `term:` 规则（`tools/arch/rules.zon` 的 `terms`）。非测试代码的字符串字面量和 `.yix` 模板文字里出现禁用词就会失败；确属合理的例外写进 `terms.allow`，并写明理由。

## 1. 主机与会话

| 指代 | 用词 | 不再使用 |
|---|---|---|
| 保存下来的连接配置（侧栏里的条目） | **主机**：新建主机、编辑主机、主机名称、主机信息、主机配置、已保存的主机、主机列表 | 连接、新建连接、编辑连接、连接配置、连接名称、连接信息、连接列表、已保存的连接 |
| 已经连上、在页签或窗格里运行的东西 | **会话**：会话详情、关闭此会话、会话已失效 | 会话连接、连接（指会话时） |

- “连接”只作动词或表示过程：连接中、连接失败、连接超时、重新连接、快速连接、连接日志、连接路径（跳板路由）。
- 网络层面的连接（SOCKS 的“N 个活跃连接”、传输的“独立传输连接”）照常使用“连接”。

## 2. 删除与移除

| 动作 | 用词 | 例子 |
|---|---|---|
| 永久去掉，不能从别处找回 | **删除** | 删除主机、删除会话记录、主机配置已删除 |
| 从列表、组或链中拿出来，对象本身还在 | **移除** | 移除附件、移除跳板、从组中移除 |

## 3. 状态

| 状态 | 用词 | 不再使用 |
|---|---|---|
| 已连上 | **已连接** | 在线 |
| 连接过程 | 连接中、重连中、认证中、断开中 | — |
| 意外断开 | 已断开 | 离线 |
| 正常结束（关闭、退出、取消） | 已结束 | 离线 |
| 连接失败 | 连接失败 | 离线 |
| 身份核验 | **认证**：认证失败、认证方式、系统认证 | 鉴权、身份验证 |

- 状态的文案、图标和色调只从 `src/shared/base/connection_presenter.zig` 取：`present(Phase)` 管会话，`presentForward(ForwardPhase)` 管 SOCKS 与端口转发。颜色由 `src/shared/ui/theme/status_tone.zig` 按当前主题给出：圆点和图标用 `dot`，文字用 `ink`。
- 连接中统一用警示色（黄色）：页签圆点、页签图标、组页签一致。失败和意外断开统一用危险色。
- 转发状态：未开启、启动中、监听中、已暂停、停止中、启动失败、清理待确认、已停止。

## 4. 关闭

- 关闭页签的动作统一叫 **关闭页签**（菜单、快捷键说明、按钮），不再写“断开并关闭”“关闭本地会话”“关闭会话连接”。
- 关闭会断开会话或结束进程时，在确认框里说明：
  - 远程会话：标题“关闭页签？”，正文开头写“关闭页签会断开此会话。”
  - 本地会话：标题“关闭页签？”，正文写“关闭页签会结束该本地会话及其进程。历史记录保留。”
- 组里的单个窗格：菜单写“关闭此会话”。
- 问号统一用全角“？”。

## 5. 错误文案

- 错误码和错误名到用户文案（标题 · 说明 · 建议）只查 `src/shared/base/error_text.zig` 一份目录。进度页、日志页、通知和插件提示都共用这份目录。
- 原始错误名（`@errorName`）不拼进用户可见文字，只放在可展开的“详情”、复制出的日志或应用日志里。目录里没有的错误，由调用方给出本领域的通用说法，比如“连接失败，请查看连接日志中的错误码”。
- HTTP 状态码的文案（模型服务等）同样在这份目录里，401 写“认证失败，请检查 API Key”。
- 同一个错误在某个领域里有更贴切的说法时，用目录里的领域查询：`theme()`（主题导入与删除）、`aiExtension()`（MCP 服务与技能），没有特例的回落到通用目录。偏好设置的保存、校验、背景图片、插件开关等错误也在这份目录里。

## 6. 主题入口

- 只保留“设置 › 外观”和菜单栏“显示 › 外观…”两处。`@theme` 只负责打开设置的外观页，不在终端里直接切换主题。
- 页签菜单、本地终端右键菜单、本地状态栏和状态栏“更多”里都不放主题入口。

## 7. 字节与速率单位

- 依据：`CONSISTENCY_AUDIT.md` 文末“用户拍板（2026-11-14）”第 4 条（2026-11-14 改判为 IEC，用户原话“那你用KiB/MiB吧”）。
- 一律按 **1024 进制**，用 **IEC 写法**：B、KiB、MiB、GiB、TiB（更大依次 PiB、EiB）；速率写 B/s、KiB/s、MiB/s、GiB/s。
- 数值与单位之间空一格；保留 1 位小数并四舍五入，整数值不带 “.0”：“0 B”、“1023 B”、“64 KiB”、“1.5 MiB”、“2 MiB”。
- 舍入后到 1024 的进到下一个单位：1023.95 KiB 写 “1 MiB”，不写 “1024 KiB”。
- 速率尚未测出（刚开始、排队、暂停）写 “— MiB/s”。
- 不再使用：KB、MB、GB、TB、KB/s、MB/s（十进制写法），以及 “× 1024 B” 之类的换算倍数后缀。
- 写法只来自 `src/shared/base/format.zig`：运行期数值用 `bytes` / `rate` / `liveRate`，固定上限用 `comptimeBytes`（由真实字节数算出，不手写）。
- 配置项按 1024 计：`chunk_kb` 后缀 “KiB”，`ring_mb` 后缀 “MiB”，`shared_pacing_kbps` 后缀 “KiB/s”（传输限速按 × 1024 字节每秒换算）。
- 冲突对比卡两侧四舍五入后的文案相同、字节数不同时，后面补精确字节数：“1 MiB · 1048600 B”。

## 8. 禁用词清单（check-arch `term:` 规则）

| 禁用词 | 改用 |
|---|---|
| 鉴权、身份验证 | 认证 |
| 在线 | 已连接 |
| 离线 | 已断开 / 已结束 |
| 断开并关闭、关闭本地会话 | 关闭页签 |
| 会话连接 | 会话 / 会话详情 |
| 新建连接、编辑连接、连接配置、连接列表、连接名称、保存的连接 | 新建主机、编辑主机、主机配置、主机列表、主机名称、已保存的主机 |
| 删除跳板 | 移除跳板 |
| 移除此主题 | 删除此主题（导入主题是永久删除） |
| “ KB”“ MB”“ GB”“ TB”、KB/s、MB/s、GB/s、kB/s、裸字面量 "KB" / "MB" | KiB、MiB、GiB、TiB、KiB/s、MiB/s、GiB/s（走 `shared/base/format`；子串匹配，“KiB”“MiB/s” 不受影响） |

白名单（`terms.allow`）：
- “编辑连接路径”：指跳板路由，不是主机。
- AI 服务提供方设置里的“连接配置”：指服务地址和 API Key，不是 SSH 主机。
- `ai/fetch_url.zig` 的“无法连接配置的代理”：这是动词“连接”接“配置的代理”，不是术语。
- `ai/lifecycle_runtime.zig` 的“不新建连接”：指网络连接的复用策略。
- `connection_presenter.zig` 自检测试：断言文案里没有“在线”。
