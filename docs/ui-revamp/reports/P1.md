## 偏差与越权

- **越权（子 agent）**：阶段 A 在沙箱外运行了 `zig version`、`zig env`，误敲一次 `perl -e1`；一个调研 agent 运行了 `python3 --version`；e2e 回归 agent 在沙箱外用了 `ps` / `pgrep` / `kill`（清理自己启动的进程）与 `sips`（图像格式转换），并写了自己的 shell 驱动脚本。都没有执行仓库代码或联网。阶段 B 为零。
- **多路复用的做法与方案文字不同**：每个现有构建步骤固定注入 `root_select`，没有新增 `-Dpreview=<name>` 选项；方案已按实做修订。
- **规则调整**：测试代码 import `platform` 改为放行；新增 `shared_ui_tests` 层不受跨 feature 限制；插件的 tests / runner 可 import 本插件内部文件。
- **`e2e/v02_grok_gateway.py`** 的改动超出“只改命令文字”：为了让 `zig build` 能在它的临时树里运行，额外复制了 `build.zig` 与 `build.zig.zon`。脚本未运行过。
- **新登记一条疑似不稳定的测试**：`terminal_execution_tests` 的 “production Local command history preserves approved AI and manual repeats across archive reopen”（驱动真实 PTY，全量时超时一次，单独重跑通过）。
